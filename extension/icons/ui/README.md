# Linux Island UI Navigation & Control Icons

**Provenance:** Project-owned minimal vector symbols created for Linux Island.  
**License:** Same as Linux Island repository (LGPL-2.1-or-later / MIT).  
**Format:** 16x16 standard SVG with `fill="currentColor"`.  
**Naming:** `*-symbolic.svg` for native recoloring in GNOME Shell (St.Icon / librsvg) and shared QML consumption.  

## Included Assets
- `media-symbolic.svg`: Musical eighth note (Media view navigation / fallback artwork)
- `system-symbolic.svg`: Control sliders (System metrics & quick toggles navigation / Settings toggle)
- `ai-symbolic.svg`: Conical laboratory flask (AI quota navigation)
- `search-symbolic.svg`: Magnifying glass (Web search navigation)
- `prev-symbolic.svg`: Skip backward transport control
- `next-symbolic.svg`: Skip forward transport control
- `play-symbolic.svg`: Play transport control
- `pause-symbolic.svg`: Pause transport control
- `volume-high-symbolic.svg`: Active speaker with audio sound wave
- `volume-muted-symbolic.svg`: Muted speaker with cross mark
- `theme-symbolic.svg`: Crescent moon for dark/light theme toggle
- `night-light-symbolic.svg`: Sun with rays for night light toggle
- `dnd-symbolic.svg`: Muted bell with slash for Do Not Disturb toggle
