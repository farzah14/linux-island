# M4: Settings application, GNOME notification fallback and security (legacy Tasks 16–18)

> **For agentic workers:** Keep shared settings source of truth in C++ Core. Never intercept/replace GNOME's notification daemon. Test on private D-Bus first, then disposable GNOME user.

**Goal:** Live Warm Minimalist preferences, zero-regression GNOME notifications, bounded and safe IPC payloads.

**Architecture:** Qt/QML preferences talk to Core1 asynchronously; Core validates/persists and signals revisions; GNOME Extension updates its locally owned rendering. Notification integration is opt-in and automatically disabled if duplicates/unsafe API are observed.

**Tech Stack:** Qt 6 Quick/QML, `QDBusPendingCallWatcher`, GNOME 46 GJS, QSaveFile, test DBus.
