# M0: GNOME Compatibility — small-step executable plan

> **For agentic workers:** Use `executing-plans` inline, one numbered card per AI turn. Follow RED→GREEN→REFACTOR. Do not mark live GNOME results PASS without testing in an actual isolated GNOME Wayland session.

**Goal:** Prove that the existing Linux Island M0 capsule, state logic and Smart Adaptive behavior work without destabilizing GNOME Shell 46 on Ubuntu Wayland.

**Architecture:** GJS ES module extension owns its St actor and local interaction state. Pure reducers and policy logic have no GNOME dependencies, so they run under Node/GJS; GNOME-specific adapter is verified against GNOME 46 before it is wired into production.

**Tech Stack:** GNOME 46 St/Clutter/GJS, JavaScript ESM, Node 20+, C++20 Qt 6 CMake, Python 3, isolated GNOME Wayland session.

## Common GNOME failures and action boundaries

| Symptom | Exact first check | Permitted next action | Forbidden shortcut |
|---|---|---|---|
| extension not found | `gnome-extensions info linux-island@local` | Confirm `metadata.json` at correct UUID path; relogin test user | Force restart live Wayland Shell |
| GNOME JS import exception | `journalctl --user -b` and actual extension error | Compare GNOME 46 module naming with target Shell sources | Guess private GNOME object names |
| Qt configure missing | `pkg-config --modversion Qt6Core` | Report missing approved system dev package | Remove `find_package(Qt6)` |
| 2 capsules after enable | Count GNOME actors, inspect `enable()` | Fix idempotence and cleanup, test 10 cycles | Add random global guard |
| missing fullscreen event | Verify GNOME/Mutter signal in actual GNOME 46 | Document API blocker; keep previous behavior | Simulate PASS from Node tests |
| theme mismatches | `tokens/tokens.json` semantic light/dark | Implement scoped theme mapping in M3 | Hardcode a new color palette |

**Stop:** If a user machine is not GNOME 46 Wayland, audit and document it. Ask before altering compatibility target; do not assume current GNOME proprietary internals are identical.
