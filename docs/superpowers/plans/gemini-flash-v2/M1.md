# M1: C++ Core + D-Bus — step cards 05–09

> **For agentic workers:** REQUIRED SUB-SKILL: `executing-plans`. One small vertical slice per invocation; RED→GREEN→test→commit. Do not claim GNOME compatibility from private D-Bus tests.

**Goal:** Versioned Core1 session bus service exposes typed snapshots/media/settings and recovers after daemon restart.

**Architecture:** Core C++ owns data/settings. `QDBusAbstractAdaptor` exposes only approved Core1. Extension GJS is an asynchronous client with a cancellable lifecycle; restarts identified by unique instance ID.

**Tech Stack:** C++20, Qt 6 Core/DBus/Test, Qt CMake, `dbus-run-session`, `gdbus`, GJS Gio.

import xml.etree.ElementTree as ET

           for e in i.findall('method')}

 'ControlMedia':[('s','in'),('b','out')], 'SetActivePlayer':[('s','in'),('b','out')],
