# M2: MPRIS media engine and Island media UI (legacy Tasks 10–13)

> **For agentic workers:** REQUIRED SUB-SKILL: `executing-plans`. Execute one small card per turn; tests first; no remote artwork downloads by default.

**Goal:** Core discovers local MPRIS players, provides normalized media metadata and validated controls, and Shell shows a safe media card.

**Architecture:** Pure metadata normalization → asynchronous MPRIS player registry → Core1 API → GJS presentation; no media protocol logic in GJS.

**Tech Stack:** Qt6 DBus/Test, MPRIS2 Player interface, GJS St/Clutter, private D-Bus integration tests.
