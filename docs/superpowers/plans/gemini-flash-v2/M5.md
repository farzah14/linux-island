# M5: Installation, crash regression, release readiness (legacy Tasks 19–21)

> **For agentic workers:** Do not tag a release without passing actual live GNOME Wayland acceptance. Install/uninstall must be user-level and reversible, without touching system packages or unrelated extensions.

**Goal:** Ship a reproducible, safe GNOME-first Linux Island v0.1 with evidence-backed acceptance, recovery, uninstall and documented limitations.

**Architecture:** User-level Core service managed by systemd; Extension installed per user; tests separate unit, private-bus integration, live Shell, and measured performance.

**Tech Stack:** systemd --user, CMake/Ninja, Qt Test, `dbus-run-session`, GJS, GNOME extensions CLI, Bash, Python 3.

## Release blocking matrix

| Failure | Release decision |
|---|---|
| No GNOME 46 Wayland runtime test | BLOCKED |
| Native notification service disrupted or duplicates | BLOCKED unless safe fallback re-established |
| Core restarts crash Shell | BLOCKED |
| MPRIS fake player works but real playback not tested | PARTIAL, AC-04 incomplete |
| Missing Qt build / Core1 introspection mismatch | BLOCKED |
| Warm Minimalist token files inconsistent | BLOCKED until QA fixed |
| Unknown license, owner namespace | No public release; local testing may continue |
| AC-10 performance not measured | No performance claim; release requires recorded baseline per approved spec |
